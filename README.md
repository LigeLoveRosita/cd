#  给朋友写的专属小彩蛋

一个专门为朋友制作的浪漫网页小彩蛋 ❤️

通过简约的暗色风格、动态动画、背景图片和音乐，为特别的人准备一份小小的惊喜。

## ✨ 项目特色

- 🎨 **简约设计**：采用深色背景与简约排版，营造温馨神秘的氛围。
- 🌌 **背景效果**：使用背景图片与模糊渐变效果，让页面更加美观。
- 🎬 **动态动画**：使用 GSAP 实现页面元素的淡入、移动和缩放动画。
- 🎵 **背景音乐**：支持循环播放背景音乐，提升浏览体验。
- 📱 **响应式布局**：适配电脑和手机等不同尺寸的屏幕。
- 💖 **专属彩蛋**：为特别的人准备的小惊喜。

## 🛠️ 使用技术

- HTML5
- CSS3
- JavaScript
- [GSAP](https://gsap.com/)
- [Font Awesome](https://fontawesome.com/)
- Google Fonts

## 🚀 如何运行

### 方法一：本地运行

1. 下载或克隆本项目。
2. 确保图片、音乐等资源文件位于正确的位置。
3. 使用浏览器打开 `index.html` 即可查看网页。

### 方法二：使用本地服务器

如果部分资源无法正常加载，可以使用 VS Code 的 Live Server 等工具启动本地网页服务器。

## 🎵 关于背景音乐

项目使用 `LonelyGirl.mp3` 作为背景音乐。

由于浏览器的自动播放限制，音乐可能需要用户点击页面后才能播放。
